# APEX — Brand Assets

Logo kit for **APEX Training Group**. Two marks — the **wordmark** (APEX) and the
**A-mark** (icon) — rendered in every core color on transparent, black, white,
and blue backgrounds, plus ready-made app icons and social sizes.

## Palette

| Name         | Hex        | Use                                  |
|--------------|------------|--------------------------------------|
| Black        | `#000000`  | Primary background                   |
| White        | `#FFFFFF`  | Reversed / light backgrounds         |
| Accent Blue  | `#0099FF`  | Brand accent, links, highlights      |
| Off-white    | `#F5F7FA`  | Light background (matches the website)|
| Metallic     | silver gradient (`#FFFFFF → #767676 → #ECECEC`) | Hero / premium — **dark backgrounds only** |
| Graphite     | brushed silver gradient (`#B9C4D1 → #3B4550 → #808C99`) | Hero / premium — **light backgrounds** |
| Blue-steel   | blue gradient (`#DFF2FF → #0099FF → #006EBE`)   | Alternate accent lockups |

**Metallic and graphite are a pair.** Metallic is a bright silver, so it
disappears on white; graphite is the same brushed-metal treatment with the
value range inverted. Pick by background, not by taste.

## Folders

- **`wordmark/`** — the APEX wordmark.
  - Transparent PNGs: `white`, `black`, `blue`, `metallic`, `graphite`,
    `blue-steel`.
  - Lockups on solid backgrounds: `…-on-black`, `…-on-white`, `…-on-blue`,
    `…-on-offwhite`.
- **`mark/`** — the standalone A-mark, same variants as the wordmark.
- **`icons/`** — rounded-square app icons at 16–1024 px in five styles:
  `metallic-black` (primary, dark), `graphite-white` (primary, light),
  `white-blue`, `blue-white`, `black-white`.
- **`social/`** — link preview, profile pic and X/Twitter header, each in a
  dark and a light cut:
  - Dark: `apx-og-1200x630`, `apx-avatar-1024`, `apx-banner-1500x500`.
  - Light: `apx-og-light-1200x630`, `apx-avatar-light-1024`,
    `apx-banner-light-1500x500`.
- **`svg/`** — infinitely scalable A-mark in white, black, blue, metallic,
  graphite.

## Which file do I use?

| Context                         | File                                             |
|---------------------------------|--------------------------------------------------|
| Light website / app / slide     | `wordmark/apx-wordmark-graphite-on-offwhite.png` |
| Dark website / app / slide      | `wordmark/apx-wordmark-metallic-on-black.png`    |
| Light document / print          | `wordmark/apx-wordmark-black-on-white.png`       |
| App icon, light UI              | `icons/apx-icon-graphite-white-1024.png`         |
| App icon, dark UI               | `icons/apx-icon-metallic-black-1024.png`         |
| Social profile picture (light)  | `social/apx-avatar-light-1024.png`               |
| Social profile picture (dark)   | `social/apx-avatar-1024.png`                     |
| Link preview, light site        | `social/apx-og-light-1200x630.png`               |
| Favicon / small UI, light       | `svg/apx-mark-graphite.svg`                      |
| Favicon / small UI, dark        | `svg/apx-mark-metallic.svg`                      |
| Print / signage (scalable)      | `svg/apx-mark-black.svg`                         |

## Usage guidelines

- **Clear space:** keep padding of at least the height of the “A” around the mark.
- **Don’t** recolor outside this palette, stretch, rotate, add drop shadows, or
  place the metallic/graphite versions on busy photos (use solid white/black
  there). Never put metallic on a light background or graphite on a dark one —
  each is built for one and vanishes on the other.
- **Minimum size:** wordmark ≥ 90 px wide; A-mark ≥ 24 px.
- Prefer **SVG** whenever the medium supports it; use PNG otherwise.
