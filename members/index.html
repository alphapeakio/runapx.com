How you get in

  1. Enter the email address you used when you enrolled.
  2. Stripe sends a one-time code to that address.
  3. Enter the code. There is no password to create or remember.

The email has to match the one on your account exactly. If you enrolled with a work address and try a personal one, no code will arrive — nothing is wrong with the page. Try the other address, or write to us and we will tell you which one we have on file.

Stuck, or not sure which email you used? Email runapx@gmail.com.
